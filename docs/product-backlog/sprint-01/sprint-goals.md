# Sprint 1: User Profile Foundation

**Duration**: April 8 - April 22, 2025  
**Goal**: Enable users to create and save their profile

---

## Objective

Build the foundational user profile system that captures all constraints needed for meal planning.

---

## Target User Stories

### Primary (Must Complete)

| Story      | Description         | Success Criteria                                                |
| ---------- | ------------------- | --------------------------------------------------------------- |
| **US-001** | Create user profile | User can input all profile fields; data is validated and saved  |
| **US-002** | Set geographic zone | User can set location and max travel distance; validation works |

### Secondary (Stretch)

| Story      | Description             | Note                                    |
| ---------- | ----------------------- | --------------------------------------- |
| **US-011** | User registration/login | Basic auth flow — can defer to Sprint 2 |

---

## What's In Scope

- Database for profile storage
- API for profile CRUD operations
- Step-by-step profile creation form (PWA)
- Postal code location with zone validation
- Form validation and error handling

## What's Out of Scope

- Menu generation
- Recipe database
- Promotion scraping
- Shopping list logic
- Social features
- Payment

---

## Definition of Done

- [ ] User can complete full profile creation flow
- [ ] Data persists in database
- [ ] Form validation works on all fields
- [ ] Mobile-responsive UI
- [ ] Unit tests for models and APIs
- [ ] PO has reviewed and approved
